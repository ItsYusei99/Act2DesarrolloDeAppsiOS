# Act2 — Desarrollo de Apps iOS

Actividad académica 2 de desarrollo de aplicaciones iOS con **SwiftUI**.

## Requisitos

- macOS con **Xcode 15+**
- iOS 17+ (simulador incluido en Xcode)

## Abrir y ejecutar

```bash
open Act2.xcodeproj
```

Dentro de Xcode: selecciona un simulador de iPhone y pulsa `⌘R`.

## Estructura

```
Act2/            # App (Act2App.swift), vista principal (ContentView.swift), assets
Act2Tests/       # Pruebas unitarias
Act2UITests/     # Pruebas de interfaz
```
